# NectarTrace User Acceptance Testing

## Target Users
- 5 Baringo beekeepers (or role-play)
- 3 urban honey buyers

## Test Scenarios

### For Farmers (USSD)
1. Dial *483# on a feature phone
2. Log harvest of 15kg
3. Check market price
4. View account summary
5. List honey for sale

### For Cooperative Staff (Web)
1. Register/login as cooperative staff
2. Register a new batch
3. View QR code
4. View stats dashboard

### For Buyers (Web)
1. Browse marketplace
2. View a listing
3. Place an order
4. Scan QR code to verify

## Success Criteria
- Farmer completes USSD flow without help: 4/5
- Buyer trusts blockchain verification: 3/3
- SUS score ≥ 70
