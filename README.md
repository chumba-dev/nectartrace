# 🍯 NectarTrace

A USSD & Blockchain Platform for Fair-Trade Honey Sourcing in Baringo County, Kenya.

## Project Info
- **Student:** Collins Kiprop Chumba
- **University:** Dedan Kimathi University of Technology
- **Type:** Final-Year Computer Science Project

## Tech Stack

### Blockchain
- Solidity ^0.8.19
- Hardhat
- Polygon Amoy Testnet
- OpenZeppelin

### Backend
- Node.js 20 LTS
- Express.js
- PostgreSQL + Prisma
- Africa's Talking (USSD)
- Ethers.js

### Frontend
- React 18 + Vite
- Tailwind CSS
- React Router
- React Query
- Recharts
